# 3D Portfolio

- **Overview:** Murtaza Baanihali’s interactive developer portfolio for recruiters, clients, and collaborators. It pairs a browser-rendered 3D presentation with conventional About, Projects, and Contact sections.
- **Public links:** [Live site](https://murtazabaanihali2.vercel.app/) · [Source](https://github.com/murtazabaanihali/3d-portfolio) · [Portfolio case study](https://dhem.io/projects/3d-portfolio)

## Product capabilities

- Visitors can browse selected projects in image carousels, read about the developer’s skills and experience, and send an inquiry through the contact form.
- The source checks WebGL support and passes the result to the scene components. The project gallery and contact form are ordinary React sections, separate from the 3D canvases.

## Stack and article angles

- React/TypeScript and Vite, Tailwind and shadcn/ui, and Three.js via React Three Fiber and Drei for the interactive scenes.
- **Possible articles:** Add WebGL as progressive enhancement without making the project list or contact form depend on it; explain where 3D adds context and where ordinary HTML does the job better.
